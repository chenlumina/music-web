## 回归与修复记录

- 修复：Tomcat 10.1 EL 5.0 不支持 record 组件取值 → 详情页改用 Map 视图模型传递数据。
- 修复：EL 浮点除法导致时长显示 `30.0:00` → Servlet 端格式化为 `m:ss`。
- 修复：品牌名在窄视口换行 → `.brand` 增加 `white-space: nowrap`。
- 回归：首页翻转卡、coverflow、弹窗、登录回跳、我的收藏在本轮全部复测通过。
